# Guitar-Chordsss

guitar chord helper thing

im so bad at remembering guitar chords lol. id try to practice, forget a chord, look it up, play for 2 seconds, then forget the next one. it literally took longer than my grandma takes to bake a batch of cookies.
so i just made this quick little web page with the 7 major chords on it. you just click the chord and it shows up right away so i don't lose my mind googling stuff constantly.

setting it up / running it

theres no setup or installing packages or anything annoying like that.
just download the files, find index.html, and double click it so it opens in your browser.

how to play

open the page, click a chord button, look at the picture, and play your guitar. pretty self explanatory.

modifying it

if you want to add minor chords or change the css just open index.html or script.js in vs code or notepad and edit it. it's just basic html/js so it's easy to mess around with.
